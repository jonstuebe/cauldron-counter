# Art manifest

Everything here is original artwork drawn for this project. SVGs are generated by
`_tools/build.mjs` (hand-authored paths, shared palette); rasters by `_tools/preview.mjs`.
`_tools/` and `preview/` carry a `.gdignore`, so Godot skips them.

Conventions

- Sizes are the SVG's native size in px. The game viewport is 1280×720; import SVGs at
  scale 2 (Import dock → Scale) wherever a sprite is shown larger than native.
- "White, tint" means the sprite is white/grey on purpose: set `modulate` / `self_modulate`.
- "Additive" means use a `CanvasItemMaterial` with `blend_mode = BLEND_MODE_ADD`.
- 9-slice margins are left, top, right, bottom in native px (`NinePatchRect` /
  `StyleBoxTexture`).
- Pivots are in native px from the top-left of the file.
- Customer index and ingredient id match `src/data.js` / `src/logic.js`.
